# XAI Image Classification App

ResNet50 / EfficientNet-B0による画像分類に、Grad-CAMによる判断根拠の可視化とファジィ論理による信頼度評価を組み合わせた、説明可能なAI（XAI）の実装です。

## 背景・目的

AIによる画像分類は高い精度を達成できる一方、「なぜその判断に至ったか」が人間には分かりにくい**ブラックボックス問題**を抱えています。特に医療診断のような人命に関わる分野では、AIの判断根拠を人間が理解できる形で説明できることが重要です。

本プロジェクトは、既存の学習済みモデルとGrad-CAM・ファジィ論理を組み合わせることで、「AIの判断 → 根拠の可視化 → 信頼性評価 → 人間向けの説明」という一連の流れを実装した、XAI（説明可能なAI）の基礎的な実装です。医療AIにおける不確実性・信頼性評価の研究に向けた前段階として位置づけています。

## 主な機能

- **画像分類**：ResNet50 / EfficientNet-B0を切り替え可能（ImageNet 1000クラス対応）
- **Top-5予測表示**：上位5クラスの確率を表示
- **Grad-CAM可視化**：入力画像・ヒートマップ・重ね合わせ画像の3枚比較
- **Grad-CAM数値化**：最大注目度・平均注目度・注目集中度を算出
- **ファジィ論理による信頼度評価**：予測確率をscikit-fuzzyでファジィ推論し、判断の信頼度を「低い／中程度／高い」で算出
- **説明文自動生成**：Groq APIを用いて、専門家向け・一般向けの2種類の説明文を生成
- **誤判定の可能性表示**：信頼度が低い場合に代替候補を提示
- **解析履歴**：過去の解析結果をデータベースに保存・一覧表示
- **カメラ機能**：ブラウザから直接撮影して解析可能

## 使用技術

| 分野             | 技術                                  |
| ---------------- | ------------------------------------- |
| 画像分類         | PyTorch（ResNet50 / EfficientNet-B0） |
| 判断根拠の可視化 | Grad-CAM                              |
| 信頼性評価       | ファジィ論理（scikit-fuzzy）          |
| 説明文生成       | Groq API（LLM）                       |
| Webアプリ        | Flask                                 |
| データベース     | SQLite                                |

## セットアップ

### 1. ライブラリのインストール

```bash
pip install -r requirements.txt
```

### 2. `.env`ファイルの作成

プロジェクト直下に`.env`を作成し、以下を記載してください。

GROQ_API_KEY=your_api_key_here

Groq APIキーは https://console.groq.com から取得できます。

### 3. 起動

```bash
python app.py
```

ブラウザで `http://127.0.0.1:5000` にアクセスしてください。

## 評価：ファジィ信頼度は誤分類を検出できるか

ファジィ論理による信頼度スコアが、実際に「モデルが間違えやすい判定」を見分けられているかを、ImageNet検証画像のサブセット（[Small-ImageNet-Validation-Dataset-1000-Classes](https://github.com/ndb796/Small-ImageNet-Validation-Dataset-1000-Classes)、ランダムに抽出した50クラス）を用いて定量的に検証した。評価スクリプトは`evaluate.py`として同梱している。

### 検証方法

各画像について、予測が正解か否か（is_correct）と、信頼度スコアを記録し、**AUROC**（信頼度スコアで正解/不正解をどれだけ判別できるかを示す指標。0.5はランダム、1.0が完全な判別を意味する）を算出した。

### 結果（第1回：softmax確率 + Grad-CAM統計 + ファジィ論理）

| 指標単体                                                        | AUROC  |
| --------------------------------------------------------------- | ------ |
| softmax確率                                                     | 0.9150 |
| ファジィ信頼度（softmax確率 + Grad-CAM最大注目度 + 注目集中度） | 0.8275 |
| Grad-CAM最大注目度 単体                                         | 0.4387 |
| Grad-CAM注目集中度 単体                                         | 0.3400 |

softmax確率単体よりも、Grad-CAM統計を組み合わせたファジィ信頼度の方が誤分類検出性能が低下する結果となった。特に注目集中度はAUROC 0.34と0.5を大きく下回っており、「注目領域が狭く集中しているほど誤分類しやすい」という、当初の想定と逆の関係を示した。これは、モデルが誤った領域に強く・狭く注目して誤答するケースが一定数存在するためと考えられる。

### 対応：入力をsoftmax確率のみに再設計

上記の結果を受け、Grad-CAM統計に基づく判別力向上という当初の設計は成立しないと判断し、ファジィ論理の入力をsoftmax確率のみに変更した。

| 指標単体                          | AUROC  |
| --------------------------------- | ------ |
| softmax確率                       | 0.9150 |
| ファジィ信頼度（softmax確率のみ） | 0.9150 |

再設計後、ファジィ信頼度はsoftmax確率と同等の判別性能を示した。この結果から、本実装におけるファジィ論理の役割は「判別精度の向上」ではなく、**連続値である確率を「低い／中程度／高い」という人間が解釈しやすい言語的なラベルへ変換する、説明可能性のための仕組み**として位置づけている。

### 考察・限界

- Grad-CAMの可視化上の"強さ"や"集中度"は、必ずしもモデルの予測の正しさと相関しない。誤った根拠に基づいて自信を持って誤答するケースが存在するため、Grad-CAM統計を信頼度計算にそのまま用いることは適切でない可能性がある。
- 評価はImageNetの50クラス・50枚という小規模なサンプルによるものであり、より大規模かつ多様な画像での再検証が今後の課題である。
- 医療画像など、ImageNetと性質の異なるドメインに適用する場合、この結論がそのまま当てはまるとは限らない。
