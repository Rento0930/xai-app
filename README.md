# XAI Image Classification App

ResNet50 / EfficientNet-B0による画像分類に、Grad-CAMによる判断根拠の可視化とファジィ論理による信頼度評価を組み合わせた、説明可能なAI（XAI）の実装です。

## 背景・目的

AIによる画像分類は高い精度を達成できる一方、「なぜその判断に至ったか」が人間には分かりにくい**ブラックボックス問題**を抱えています。特に医療診断のような人命に関わる分野では、AIの判断根拠を人間が理解できる形で説明できることが重要です。

本プロジェクトは、既存の学習済みモデルとGrad-CAM・ファジィ論理を組み合わせることで、「AIの判断 → 根拠の可視化 → 信頼性評価 → 人間向けの説明」という一連の流れを実装した、XAI（説明可能なAI）の基礎的な実装です。医療AIにおける不確実性・信頼性評価の研究に向けた前段階として位置づけています。

## 主な機能

- **画像分類**：ResNet50 / EfficientNet-B0を切り替え可能（ImageNet 1000クラス対応）
- **Top-5予測表示**：上位5クラスの確率を表示
- **Grad-CAM可視化**：入力画像・ヒートマップ・重ね合わせ画像の3枚比較
- **Grad-CAM数値化**：最大注目度・平均注目度・注目集中度を算出
- **ファジィ論理による信頼度評価**：予測確率とGrad-CAM指標をscikit-fuzzyで統合し、判断の信頼度を算出
- **説明文自動生成**：Groq APIを用いて、専門家向け・一般向けの2種類の説明文を生成
- **誤判定の可能性表示**：信頼度が低い場合に代替候補を提示
- **解析履歴**：過去の解析結果をデータベースに保存・一覧表示
- **カメラ機能**：ブラウザから直接撮影して解析可能

## 使用技術

| 分野 | 技術 |
|---|---|
| 画像分類 | PyTorch（ResNet50 / EfficientNet-B0） |
| 判断根拠の可視化 | Grad-CAM |
| 信頼性評価 | ファジィ論理（scikit-fuzzy） |
| 説明文生成 | Groq API（LLM） |
| Webアプリ | Flask |
| データベース | SQLite |

## セットアップ

### 1. ライブラリのインストール

```bash
pip install -r requirements.txt
```

### 2. `.env`ファイルの作成

プロジェクト直下に`.env`を作成し、以下を記載してください。
GROQ_API_KEY=your_api_key_here

Groq APIキーは https://console.groq.com から取得できます。

### 3. 起動

```bash
python app.py
```

ブラウザで `http://127.0.0.1:5000` にアクセスしてください。
